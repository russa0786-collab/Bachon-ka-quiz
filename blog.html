السلام علیکم! میں نے اپنے بچوں کے لیے ایک اسلامی کوئز ویب سائٹ بنائی۔

🎮 میرا کوئز دیکھیں

1۔ کوڈ کہاں سے لیا؟

میں نے Meta AI سے کہا "بچوں کے لیے اسلامی کوئز کا HTML کوڈ دو" تو اس نے بنا دیا۔ آپ کو خود لکھنے کی ضرورت نہیں۔

2۔ سائٹ کیسے بنائی؟

سٹیپ 1: GitHub اکاؤنٹ

github.com پر جائیں اور Bachon-ka-quiz نام کا Repository بنائیں۔

سکرین شاٹ 1: Repository بنانا

سٹیپ 2: کوڈ پیسٹ

Add file > Create new file > نام index.html > کوڈ پیسٹ > Commit changes

سکرین شاٹ 2: کوڈ پیسٹ کرنا

سٹیپ 3: سائٹ آن

Settings > Pages > Branch main > Save۔ 2 منٹ بعد لنک ملے گا۔

💡 آپ کی سائٹ کا لنک ایسا ہوگا: https://russa0786-collab.github.io/Bachon-ka-quiz/

3۔ اپنی سکرین شاٹ کیسے لگائیں؟

اپنی تصویر imgbb.com پر اپلوڈ کریں اور اس کا لنک اوپر img src میں ڈال دیں۔

4۔ نیا سوال کیسے ایڈ کریں؟

اسی index.html میں جائیں اور جہاں سوال لکھے ہیں وہاں نیا سوال لکھ دیں۔
